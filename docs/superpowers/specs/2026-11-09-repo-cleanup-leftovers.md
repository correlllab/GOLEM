# Repo cleanup: findings kept, listed or left for the package owners

The 2026-11-09 cleanup (branch `repo_cleanup`, from GOLEM 1e86e92) applied the
dead-code audits of `golem_robocasa`, `tests/`, `tools/`, `golem_safety`,
`golem_upper_ik`, `dex_3`, `golem_ros2_models`, `golem_lowerbody_rl`, `golem_slam`,
`golem_skills`, `golem_bringup`, `lmg_deploy`, `model_server`, `docker/` and `docs/`.
This page lists every finding it deliberately did not apply, so that each package's
owner (CLAUDE.md §5) can decide. The submodules' findings are in
`2026-11-09-submodule-dead-code.md`.

How to read a row:

- **Where** is file and line at the branch tip (`cefe634`), checked against the tree.
- **Why kept** is one of: *user decision* (the user ruled on 2026-11-09), *behaviour*
  (changing it changes what a robot, a sim or a refusal message does, and no user
  decision covers it), *cross-package* (the copies are in packages that do not depend
  on each other, and CLAUDE.md §5 forbids inventing a shared library inside a
  cleanup), *audit wrong* (the finding's evidence was incomplete), *seam* (tests or a
  documented surface use it), or *churn* (the change costs more than it saves).
- **Decision** is what the owner has to settle before anyone changes the row.

The audits were working files outside the repository; every row here carries its own
evidence.
